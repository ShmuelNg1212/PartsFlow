# Hosted PaddleOCR scanner

Date: 2026-10-18. Mode: technical. Study: [hosted OCR study](../study/1792323827_hosted_ocr.md).
Branch: `feat/hosted-ocr`. Rules: R-EXT-1, R-EXT-2, R-EXT-3, R-EXT-4. ADRs: 0002, 0005.

Status: **awaiting approval.** Do not execute before the human answers the open questions.

## OPEN QUESTIONS

1. **Host.** Approve Google Cloud Run in `asia-southeast1` (Singapore), scale to zero? The alternative is an always-on Hetzner server (about €16/month in Germany, about €49/month in Singapore).
2. **Cost.** Approve a Google Cloud billing account? The expected cost at pilot volume is near $0. Cap: max 2 instances. Do you also want a budget alert (for example $10/month)?
3. **Privacy.** Approve that invoice files go from Supabase to Google Cloud Run in Singapore for reading? The worker stores nothing and logs no content. This becomes ADR 0006.
4. **Scope of the live switch.** Turn on the hosted scanner in development only, or in development and then production? Production has no shop yet. Real invoices still need shop consent (roadmap step 2).
5. **Cold start.** If a cold start plus one read takes more than about 120 s, the user gets "enter the lines by hand" on the first upload. Accept this, or pay for one always-on instance (exact cost measured in T5)?

## Decisions recorded (routine, reversible)

- The hosted provider label is `paddleocr`. The local label stays `paddleocr-local`.
- The Edge Function uses PaddleOCR only when `OCR_WORKER_URL` (HTTPS) and `OCR_WORKER_TOKEN` are both set. Otherwise it keeps the demo extractor. Unsetting the URL is the rollback.
- The worker call timeout in the Edge Function is 120 s. The Free plan wall clock is 150 s.
- Cloud Run concurrency is 1. The worker reads one file at a time.
- The image contains the pinned models. Cold starts do not download models.
- The image is built by Cloud Build. This Mac has no Docker.
