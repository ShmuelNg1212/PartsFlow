## OPEN QUESTIONS

## Decisions recorded

- No motion library. CSS transitions, `@starting-style`, and Tailwind classes cover every item.
- The global reduced-motion rule stays. New entrances become instant under that preference.
- The human overrides the study §5 rejection of route transitions. Task 1b adds them. They stay short and entry-only, so navigation does not wait.
- No exit animations. Alerts and steps leave at once, so the user acts without delay.
- One commit per task group: `feat:` for tasks 1–5, `docs:` for task 6.
